# NiviTrack iPhone 使用手冊

NiviTrack 是一個為 iPhone Safari 設計的本機影片後製 Web App。選擇 MOV、HEVC 或 MP4 影片後，可使用 6 種濾鏡、4 種裁切、ViT 主角置中，以及第 12 項「單一舞者去背」。去背會只保留被選定與追蹤的舞者，其他人物、物品和背景輸出為純黑。

影片與追蹤工作都在使用者自己的 iPhone 內完成，不會上傳到 GitHub 或其他伺服器。

第 12 項使用 Apache-2.0 的 `@mediapipe/tasks-vision` 與 Google MediaPipe Selfie Segmenter 模型。每幀會先依 ViT 追蹤框裁出選定舞者的局部畫面，再執行人物分割，避免整個複雜背景與其他舞者降低辨識率。WASM 與約 250 KB 的模型由同一個 GitHub Pages 靜態網站提供；首次載入後，所有逐幀推論與黑底合成都在 Safari 本機執行，不需要 API、後端或付費伺服器。

## 第一次安裝到 iPhone 主畫面

1. 讓 iPhone 連接網路。
2. 使用 **Safari** 開啟 NiviTrack Web App。
3. 點 Safari 的「分享」按鈕。
4. 向下找到並點選「加入主畫面」。
5. 名稱保留為 **NiviTrack**，再點「加入」。
6. 回到主畫面，點 NiviTrack 圖示啟動。

第一次使用時，建議保持連線並完成一次「測試 3 秒 ViT」，讓必要的 AI 模型與程式資源載入完成。

## 處理一支影片

### 1. 選擇影片

1. 點「選擇影片」。
2. 從「照片」或「檔案」選擇 MOV、HEVC 或 MP4。
3. 等待狀態顯示「影片已在本機載入」。
4. 可先播放影片尋找主角清楚的畫面；進入「主角鎖定置中」或「單一舞者去背」後，也能直接點「播放找畫面」。

NiviTrack 會直接讀取原始影片，不需要先轉成 MP4。

### 2. 指定主角

1. 選擇「主角鎖定置中」或「單一舞者去背」。
2. 如果畫面是黑的或停在不合適的位置，點「播放找畫面」，再點「暫停並框選」。
3. 用手指拖曳方框，完整框住要追蹤的人物或寵物。
4. 若不方便手動畫框，可點「AI 尋找人物／寵物」，再選擇辨識框。
5. 框錯時可直接重新拖曳，或播放後換一個較清楚的畫面。

方框盡量只包含主角，但要保留完整身體，不要切掉頭部或四肢。

### 3. 先做 3 秒測試

1. 點「測試 3 秒 ViT」。
2. 等待進度到 100%。
3. 觀察框線是否能跟著主角移動。

3 秒測試不會輸出影片。若追蹤容易跑掉，請點「重新框選」，選擇主角較大、較清楚且遮擋較少的畫面後再測試。

若使用「單一舞者去背」，點「準備 3 秒去背預覽」，等待本機模型準備完成，再點「播放 3 秒去背預覽」。這段預覽會動態播放選定舞者並將其他畫面合成為純黑；不會輸出影片，也可重播。

完成整支影片追蹤後，去背與主角鎖定都能調整 `9:16／1:1／16:9`、主角大小 `25–80%` 與置中柔順度 `0–100%`。去背遮罩另會柔性內縮輪廓並要求新區域連續兩幀成立，以減少緊貼主角的背景與單幀閃漏。

「3 秒去背 Preview」在初始框選測試與完整追蹤後的構圖頁都可使用。若直接跳過初始 3 秒測試，構圖頁會先顯示「準備 3 秒去背 Preview」；完成後即可播放及重播，預覽結束仍會回到原本的比例與主角大小設定頁。

### 4. 追蹤完整影片

1. 確認 3 秒測試正常。
2. 點「追蹤完整影片」。
3. 將 NiviTrack 保持在前景，不要鎖定螢幕或切換到其他 App。
4. 等待狀態顯示「完整 ViT 路徑已建立」。

追蹤時間會隨影片長度增加。處理長影片時，iPhone 發熱或耗電增加屬正常現象。

### 5. 選擇輸出構圖

- **9:16**：直式手機影片
- **1:1**：正方形影片
- **16:9**：橫式影片
- **主角大小**：數值越大，主角在成品中越大
- **置中柔順度**：數值越高，鏡頭移動越平順

第一次可直接使用預設值：9:16、主角大小 55%、置中柔順度 72%。

### 6. 輸出與儲存

1. 一般分享建議點「輸出相容 MP4」。
2. 若「輸出 HEVC 母片（MP4）」可用，也能選擇 HEVC 以節省容量。
3. 輸出時保持 NiviTrack 在前景，不要鎖定螢幕。
4. 等待成品預覽出現，播放確認畫面、聲音與長度。
5. 點「分享／儲存到 iPhone」。
6. 從 iPhone 分享選單選擇「儲存影片」或「儲存到檔案」。

「HEVC 母片」的容器是 MP4，不是 MOV。若 HEVC 按鈕無法使用，請改用相容性最高的 H.264 MP4。

## 處理下一支影片

完成測試、追蹤或輸出後，點「重新選擇影片」即可選擇下一支影片。舊影片的框選、追蹤路徑與輸出結果會自動清除。

## 安裝到另一台 iPhone

不需要移動程式檔，也不需要提供 GitHub 帳號或密碼。

1. 在另一台 iPhone 使用 Safari 開啟 Web App 網址。
2. 依照「第一次安裝到 iPhone 主畫面」操作。
3. 在那台手機上完成一次 3 秒測試。

兩台 iPhone 的影片、框選、追蹤結果與輸出檔彼此獨立，不會自動互傳。若要分享成品，請使用 AirDrop、訊息、共享相簿或其他 iPhone 分享方式。

## 隱私與網路

- 原始影片不會上傳到 GitHub。
- GitHub Pages 只提供 Web App 程式與 AI 模型檔案。
- 第一次開啟及第一次載入 AI 模型時需要網路。
- 完成首次載入後可嘗試離線使用；若 iOS 清除網站快取，仍需重新連線載入。
- Repository 與 Web App 都是公開的，任何知道網址的人都能查看程式或使用 App，但無法看到其他使用者手機裡的影片。

## 常見問題

### 一直顯示「正在檢查 Safari…」

1. 從多工畫面將 NiviTrack 往上滑關閉。
2. 確認網路正常。
3. 從主畫面重新開啟 NiviTrack。
4. 若仍未恢復，再關閉並開啟一次。

### 影片畫面是黑的

先按播放確認 Safari 能否解碼影片。進入主角鎖定或去背後仍可點「播放找畫面」，再以「暫停並框選」停在主角清楚的位置。

### 追蹤框跑掉

重新框選主角，並注意：

- 選擇主角輪廓清楚的影格。
- 完整框住主角，避免框入太多背景。
- 避開嚴重遮擋、快速轉身或主角太小的畫面。
- 先通過 3 秒測試，再進行完整追蹤。

去背時若某幾幀因遮擋或快速動作暫時辨識不到舞者，NiviTrack 會短暫沿用並淡出上一幀遮罩；若影片開頭尚未出現舞者，該段保持純黑，不會再中止整支影片輸出。

### 輸出中斷或沒有聲音

- 保持 NiviTrack 在前景並讓螢幕持續開啟。
- 確認 iPhone 有足夠儲存空間與電量。
- 先改用「輸出相容 MP4」。
- 關閉 NiviTrack、重新開啟，再重新處理影片。

### 主畫面的功能沒有更新

從多工畫面完全關閉 NiviTrack，再由主畫面重新開啟。網址和主畫面圖示不需要更換。

## 使用限制

- 目前以 iPhone 16 Pro／Pro Max、iOS 26、Safari 為主要測試環境。
- 其他裝置與瀏覽器尚未列入驗證範圍。
- 長影片需要較長處理與輸出時間，並可能增加耗電與發熱。
- 網頁版無法保證所有 Safari 版本都提供 HEVC 編碼；H.264 MP4 是建議的通用輸出格式。
