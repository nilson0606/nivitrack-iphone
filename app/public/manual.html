NiviTrack 使用手冊
安裝說明 開啟 App
IPHONE · SAFARI · 本機處理

從選片到輸出，照著做就好。

NiviTrack 直接讀取 iPhone 裡的 MOV、HEVC 或 MP4，提供濾鏡、裁切、主角鎖定與單一舞者去背共 12 種單一後製。影片不會上傳。

立即開啟 NiviTrack
支援範圍：iPhone、iOS 26、Safari。
安裝到主畫面 完整操作流程 輸出與儲存 下一支影片 另一台 iPhone 常見問題

第一次安裝到 iPhone 主畫面

  1. 讓 iPhone 連接網路。
  2. 使用 Safari 開啟 NiviTrack 網址。
  3. 點 Safari 的「分享」按鈕。
  4. 向下找到並點「加入主畫面」。
  5. 名稱保留為 NiviTrack，再點「加入」。
  6. 回到主畫面，點 NiviTrack 圖示。

第一次使用請保持連線。「主角鎖定置中」與「單一舞者去背」才會載入 ViT；去背會在首次準備 3 秒預覽或輸出時載入開源 MediaPipe 模型。濾鏡與裁切不需要 AI。

一般操作流程

1
選擇影片

從「照片」或「檔案」選擇 MOV、HEVC 或 MP4。等待顯示影片已在本機載入，不需要先轉成 MP4。

2
選擇一項功能

預設不會追蹤。從 6 種濾鏡、4 種裁切、「主角鎖定置中」或「單一舞者去背」中選一項。

3
預覽與調整

濾鏡可調效果強度；固定比例裁切可調位置與縮放；自由裁切則直接用手指框出要保留的範圍。

4
選畫質並輸出

預設為「清晰」最高 1080p；需要較快速度時可改選「標準」最高 720p。點「輸出相容 MP4」並保持 App 在前景，原聲會保留。

一次只處理一項。若要疊加效果，先輸出，再把成品重新匯入並選下一項功能。

12 種功能

  • 濾鏡：鮮明增色、柔和人像、電影冷調、暖陽色調、黑白高反差、復古底片。
  • 裁切：直式 9:16、方形 1:1、橫式 16:9、自由裁切與縮放。
  • 鎖定：主角鎖定置中（ViT）。
  • 去背：單一舞者去背；去背後可選背景顏色或模糊原片，並加人物外框與 0～4 人分身。

單一舞者去背

  1. 選「單一舞者去背」。若一開始黑屏或畫面不合適，點「播放找畫面」，再點「暫停並框選」。
  2. 用手指緊貼框住要保留的舞者，或點「AI 尋找人物」後選中正確人物框。
  3. 選擇背景顏色或模糊原片；人物外框提供「無框／細框／粗框」快速選項，也可自訂顏色與 0～48px 厚度。
  4. 分身可選 0～4 人；「前後殘影」會保留短暫的動作軌跡，「左右併排」會排列同一影格的分身。
  5. 點「準備 3 秒去背預覽」，完成後再點「播放 3 秒去背預覽」確認去背與特效。
  6. 確認後可重播預覽，或繼續追蹤完整影片。完整追蹤後仍可調整特效、9:16／1:1／16:9、主角大小與置中柔順度。
  7. 輸出相容 MP4。每幀會先在 iPhone 本機執行 MediaPipe 人物分割，再套用後製特效，原聲照常保留。

多人畫面會先依 ViT 追蹤框裁出局部區域，再分割被選取的舞者。框選要包含主角完整頭部與四肢，但不要包入其他舞者。遮罩依每個影格的追蹤框與相對信心，自動切斷舞者與背景區域之間的狹窄黏連，不依賴特定物品或固定形狀，並抑制單幀閃漏。短暫遮擋會淡出上一幀遮罩，影片開頭尚未出現主角時保持純黑。主角手持物品在第一版會視為背景移除。

主角鎖定置中

  1. 先播放後暫停在主角清楚的畫面。
  2. 選「主角鎖定置中」，用手指框住人物或寵物；也可使用 AI 尋找候選框。
  3. 先跑 3 秒 ViT 測試，再追蹤完整影片。
  4. 調整輸出比例、主角大小與置中柔順度後輸出。

追蹤及輸出期間，請保持 NiviTrack 在前景，不要鎖定螢幕或切換到其他 App。

輸出與儲存

9:16直式手機影片
1:1正方形影片
16:9橫式影片
  • 清晰：預設選項，最高輸出 1080p，位元率較高；畫面較清楚，但編碼較久、檔案較大。
  • 標準：最高輸出 720p，速度較快、較省記憶體。
  • 裁切：固定比例可移動畫面中心並放大；自由裁切可用手指框出任意比例。
  • 主角鎖定：可選 9:16、1:1 或 16:9，並調整主角大小與柔順度。
  • 去背：可選 9:16、1:1 或 16:9，並輸出所選背景、外框與分身效果。
  • 原聲：所有 12 種功能都會沿用來源影片的聲音。
  1. 一般分享請點「輸出相容 MP4」。
  2. 保持 App 在前景；完成後畫面會自動捲到成品與分享按鈕。
  3. 播放確認畫面、聲音與影片長度。
  4. 點一次「分享／儲存到 iPhone」，開啟 iPhone 分享選單。
  5. 選「儲存影片」或「儲存到檔案」。

「HEVC 母片」輸出的是 MP4，不是 MOV。若 HEVC 按鈕無法使用，請改用相容性最高的 H.264 MP4。

處理下一支影片

完成測試、追蹤或輸出後，點 「重新選擇影片」即可選擇下一支影片。

舊影片的框選、追蹤路徑與輸出結果會自動清除，不需要刪除或重新安裝 App。

安裝到另一台 iPhone

不需要搬移程式檔，也不需要 GitHub 帳號或密碼。

  1. 在另一台 iPhone 使用 Safari 開啟 NiviTrack 網址。
  2. 使用 Safari 的「加入主畫面」。
  3. 從主畫面啟動。若要使用主角鎖定或去背，第一次請保持連網讓 ViT、MediaPipe 與人物分割模型載入。

每台手機的影片與輸出檔彼此獨立，不會自動互傳。成品可使用 AirDrop、訊息或共享相簿分享。

隱私與網路

  • 原始影片與輸出影片都不會上傳到 GitHub。
  • GitHub Pages 只提供 Web App 程式與 AI 模型。
  • 第一次開啟及第一次載入 AI 模型時需要網路。
  • 首次載入後可嘗試離線使用；若 iOS 清除快取，需要重新連線載入。
  • 網站與程式碼是公開的，但其他人無法看到你手機裡的影片。

常見問題

一直顯示「正在檢查 Safari…」
從多工畫面將 NiviTrack 往上滑關閉，確認網路正常，再由主畫面重新開啟。若仍未恢復，再關閉並開啟一次。
影片畫面是黑的
先按播放，確認 Safari 能解碼影片。進入主角鎖定或去背後仍可點「播放找畫面」，再以「暫停並框選」停在清楚畫面。若只有裁切預覽異常，先返回功能選單再重新選擇該裁切。
追蹤框跑掉
重新框選主角。選擇主角輪廓清楚的畫面，完整框住主角並減少背景，避開嚴重遮擋。先通過 3 秒測試，再做完整追蹤。
輸出中斷或沒有聲音
保持 NiviTrack 在前景、確認電量與儲存空間充足，並優先使用「輸出相容 MP4」。仍有問題時，關閉 App 後重新開啟再處理。
主畫面的功能沒有更新
從多工畫面完全關閉 NiviTrack，再由主畫面重新開啟。網址和主畫面圖示都不需要更換。
