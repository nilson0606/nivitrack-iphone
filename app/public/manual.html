IPHONE · SAFARI · 本機處理

從選片到輸出，照著做就好。

NiviTrack 直接讀取 iPhone 裡的 MOV、HEVC 或 MP4，追蹤指定主角並輸出置中構圖的影片。影片不會上傳。

立即開啟 NiviTrack
支援範圍：iPhone、iOS 26、Safari。本專案不支援 Windows PC。

第一次安裝到 iPhone 主畫面

  1. 讓 iPhone 連接網路。
  2. 使用 Safari 開啟 NiviTrack 網址。
  3. 點 Safari 的「分享」按鈕。
  4. 向下找到並點「加入主畫面」。
  5. 名稱保留為 NiviTrack，再點「加入」。
  6. 回到主畫面，點 NiviTrack 圖示。

第一次使用請保持連線，並完成一次「測試 3 秒 ViT」，讓 AI 模型與離線資源載入完成。

完整操作流程

1
選擇影片

從「照片」或「檔案」選擇 MOV、HEVC 或 MP4。等待顯示影片已在本機載入，不需要先轉成 MP4。

2
播放後暫停

找到主角清楚、較大、遮擋較少的畫面，然後暫停。

3
指定主角

點「進入主角選取」，用手指完整框住人物或寵物。也可點「AI 尋找人物／寵物」。

4
先測試 3 秒

點「測試 3 秒 ViT」，確認框線能跟著主角。這一步只測試，不會輸出影片。

5
追蹤完整影片

測試正常後點「追蹤完整影片」，等待顯示「完整 ViT 路徑已建立」。

追蹤及輸出期間，請保持 NiviTrack 在前景，不要鎖定螢幕或切換到其他 App。

構圖、輸出與儲存

9:16直式手機影片
1:1正方形影片
16:9橫式影片
  • 主角大小：數值越大，主角在成品中越大。
  • 置中柔順度：數值越高，鏡頭移動越平順。
  • 建議預設：9:16、主角大小 55%、置中柔順度 72%。
  1. 一般分享請點「輸出相容 MP4」。
  2. 保持 App 在前景並等待成品預覽出現。
  3. 播放確認畫面、聲音與影片長度。
  4. 點「分享／儲存到 iPhone」。
  5. 選「儲存影片」或「儲存到檔案」。

「HEVC 母片」輸出的是 MP4，不是 MOV。若 HEVC 按鈕無法使用，請改用相容性最高的 H.264 MP4。

Stage 1：人物去背與延遲分身

Clone 是同一個主角形成的分身／彩色殘影，不做換臉，也不使用生成式 AI 產生另一個人物。程式先依 ViT 與 MagicTouch 鎖定原主角，再以 Pose 人體遮罩排除電風扇、家具等非人體物件；逐格去背完成後才加入邊框與分身。

  1. 先完成整支影片的 ViT 追蹤。
  2. 在「人物去背與延遲分身」點「開啟特效」。
  3. 背景選擇：原始、純黑或模糊。
  4. 主角選擇：原色、藍色剪影或黑色剪影。
  5. 邊框選擇：白邊、霓虹光或無邊框。
  6. 分身排列選擇「前後殘影」或「左右並排」。
  7. 設定 0～4 個分身、0～1 秒延遲、透明度與顏色。
  8. 點「測試 3 秒特效」。
  9. 測試完成且滿意後，再輸出完整影片。

人物去背以 30 FPS 先逐格分析，不要求模型追著影片播放速度跑；遮罩不會被追蹤框硬裁，可隨手腳動作延伸。更改構圖或任何特效設定後，必須重新完成 3 秒特效測試。完整輸出會保留原聲。兩個人完全重疊時仍可能有邊緣誤差。

Stage 2：進階特效規劃

  • 連續殘影：動作後方留下多層影子。
  • 定格分身：每隔一段時間留下固定姿勢。
  • 鏡像分身：左右對稱複製主角。
  • 聚光燈：背景變暗，只照亮主角。
  • RGB 分離：紅、綠、藍三個錯位分身。
  • 瞬間閃現：分身依節奏出現與消失。
  • 背景替換：純色、照片或漸層背景。

Stage 2 會在 Stage 1 通過 iPhone 實機測試後再開始。

處理下一支影片

完成測試、追蹤或輸出後，點 「重新選擇影片」即可選擇下一支影片。

舊影片的框選、追蹤路徑與輸出結果會自動清除，不需要刪除或重新安裝 App。

安裝到另一台 iPhone

不需要搬移程式檔，也不需要 GitHub 帳號或密碼。

  1. 在另一台 iPhone 使用 Safari 開啟 NiviTrack 網址。
  2. 使用 Safari 的「加入主畫面」。
  3. 從主畫面啟動，並在連網時完成一次 3 秒測試。

每台手機的影片與輸出檔彼此獨立，不會自動互傳。成品可使用 AirDrop、訊息或共享相簿分享。

隱私與網路

  • 原始影片與輸出影片都不會上傳到 GitHub。
  • GitHub Pages 只提供 Web App 程式與 AI 模型。
  • 第一次開啟及第一次載入 AI 模型時需要網路。
  • 首次載入後可嘗試離線使用；若 iOS 清除快取，需要重新連線載入。
  • 網站與程式碼是公開的，但其他人無法看到你手機裡的影片。

常見問題

一直顯示「正在檢查 Safari…」
從多工畫面將 NiviTrack 往上滑關閉，確認網路正常，再由主畫面重新開啟。若仍未恢復，再關閉並開啟一次。
影片畫面是黑的
先按播放，確認 Safari 能解碼影片。看得到畫面後，暫停在主角清楚的位置，再進入主角選取。
追蹤框跑掉
重新框選主角。選擇主角輪廓清楚的畫面，完整框住主角並減少背景，避開嚴重遮擋。先通過 3 秒測試，再做完整追蹤。
輸出中斷或沒有聲音
保持 NiviTrack 在前景、確認電量與儲存空間充足，並優先使用「輸出相容 MP4」。仍有問題時，關閉 App 後重新開啟再處理。
主畫面的功能沒有更新
從多工畫面完全關閉 NiviTrack，再由主畫面重新開啟。網址和主畫面圖示都不需要更換。
